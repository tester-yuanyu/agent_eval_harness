# 评测质量补齐设计

用户授权自行补齐上一轮审计发现的工程与文档缺口。本轮范围为本仓库中的可离线完成工作；独立人工标签与新的付费 Agent / Judge 执行不能由自动生成结果冒充。

## 目标与选择

采用“复用已有证据、补齐诊断与验收材料”的方式。直接增加真实评测会在标准未稳定时增加成本；只补说明文档无法补上独立重复调用诊断和可用标注入口。保留 Inspect 执行、DeepEval 正式评分、GEval 诊断的职责。

## 交付

1. 文件工具轨迹的重复调用候选诊断：仅使用公开工具参数、轮次、前后工作区快照和错误状态。区分同状态重复、错误后重试、状态变化和证据不足。候选不证明无必要，不改变正式 verdict；每条记录保留事件引用和规则版本。仅对可观察本地文件状态成立。
2. 校准比较增强：按维度给出一致性、MAE、混淆矩阵、误放/误杀、覆盖率及可追踪差异；标注材料保留空白人工字段，附人工来源验证。离线标注页可导出标签，不展示 Judge 预测。机器编写的分档示例明确为说明材料、待人工审定。
3. 当前 benchmark 指标规格：统一公式、粒度、分母、范围、缺失处理、正式/诊断角色、证据及版本。与旧 Inspect 指标字典分开。
4. 用保存的真实运行生成本轮质量检查记录：Trace 新诊断统计、既有 Judge 稳定性、空白人工标注状态和已有同口径 v1 配置对比。不得将复评算为新执行或将 v1/v2 评分差异称为 Agent 提升。

## 约束

- 不修改冻结任务、期望答案、已有报告和历史结果；新分析写新目录。
- 不调用真实模型或托管服务，不读出或复制凭据。
- 新评分代码进入评分身份 Hash；正式评分规则未变时仍需为诊断集变化标记新版本。
- 缺证据不记为正常；无工具调用不记为满分；重复候选不自动判定失败。
- 校准工具不能将空标签、模型标签或同一批数据上的阈值拟合宣称为独立验收。
- 现有 36 条样本属于开发/试标材料；未参与调整的独立验收样本和人工标注仍须另行完成。
- 各代理只编辑分配文件，不暂存或提交；由协调者整合。

## 验收

关键边界的离线测试、Evaluator 回归、根集成检查、冻结资产校验，以及全新本地克隆安装和离线 Demo。保存可读报告和机器可读来源 Hash；费用缺乏可靠记录时保留未知。
