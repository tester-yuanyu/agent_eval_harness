用户已确认上一轮 P0/P1/P2 方案并要求执行。采用现有可选展示层扩展，不改 Agent、冻结结果、正式评分及执行链路，不调用模型。

目标：从失败分类或任务族定位准确用例，再进入完整 Trace；顶部展示健康度，趋势按固定口径跨 run 汇总。先保证下钻准确，再补卡片和图表。

选择：优先使用 Langfuse 原生筛选列表及 View as table。当前云端不支持或过滤转换丢失时，交付带精确 Trace 链接的离线调试入口及核验过的 Langfuse 筛选 URL；不修改托管产品前端，不宣称柱子自动联动。与其单纯扩充图表，优先保证操作路径可验证。

口径：task 根节点用于端到端延迟；generation 用量仅统计一次；cached 是输入子集；实际费用缺失保留未知，订阅额度价值另作带上下限的估算；工具均值为实际调用数/全部 trial。现有正式 Score 保留适用范围及分母，不制造新的正式评分。仅一模型时不虚构多模型对比。
