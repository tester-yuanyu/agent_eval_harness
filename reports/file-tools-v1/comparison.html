结论适用范围

  • 仅四种本地文件工具；是真实 nanobot SDK 的受限配置，不代表原生全工具能力或生产安全性。
  • 300 条合成实例来自 80 个任务族，未经过用户逐条人工审核；不能称为官方 τ-bench / BFCL / SWE-bench 成绩。
